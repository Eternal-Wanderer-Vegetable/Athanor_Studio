1. 炼金术意象：最贴合“转化”

把 doc、pdf、md、html 当成不同“贱金属”，统一炼成 .udoc 这种“黄金”。

层级 名称 现实意象
格式 Azoth / .azoth 炼金术中的万能溶剂、万用精华
引擎 Athanor / athanor 炼金术士的长明炉，长时间转化物质
编辑器 Aludel / aludel 炼金升华罐，提炼、编辑
中间模型 Prima Materia / prima 原初物质，对应统一中间模型
导出器 Transmuter / transmute 转化器
GUI Athanor Studio 炼金工坊

口号：“万物入炉，一炼成书。”

优点：转化意象极强，且 Athanor、Azoth、Aludel 比 Forge、Codex 更少见。
缺点：偏神秘，普通人第一次听不一定懂。
